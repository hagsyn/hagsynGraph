# Hagsyn Information Architecture

## 文档目标

定义 Hagsyn 当前阶段的信息架构，明确各主模块的职责、边界和相互关系，避免后续产品扩展时出现模块重叠或语义漂移。

## 总体结构

Hagsyn 当前采用统一工作台结构，一级导航保持为：

- `Dashboard`
- `Tools`
- `Nodes`
- `Graph`
- `Roadmaps`

这五个模块共同组成产品的稳定骨架。即使某些模块当前仍处于轻量状态，也不应随意删改命名或改成与整体语义无关的页面。

## 信息架构原则

### 1. 一级导航代表长期产品模块

一级导航不是临时栏目，而是长期产品能力分区。新增功能优先放入已有模块，不轻易新增并列一级入口。

### 2. Tools 与 Knowledge 分层

`Tools` 是真实执行层，`Nodes / Graph / Roadmaps` 是知识承载层，两者要保持关联，但不要混成一个含义模糊的“全功能页”。

### 3. 页面先服务任务，再服务展示

页面的主要职责是帮助用户完成当前任务，而不是展示概念完整性。

### 4. 当前空白是刻意留白

Knowledge 模块在当前阶段允许轻量、允许少数据，但不允许用伪造内容填充。

## 一级模块定义

### Dashboard

`Dashboard` 是工作台首页，不是营销首页。

当前职责：

- 展示系统当前状态
- 汇总已接入真实工具
- 给出下一步可执行动作
- 为后续 Knowledge 建设保留状态入口

当前不承担的职责：

- 不做大段品牌宣传
- 不做虚假数据概览
- 不模拟完整运营大盘

### Tools

`Tools` 是当前最核心的主工作区。

当前职责：

- 承载真实可执行工具
- 作为工具目录和工具入口
- 展示每个工具的状态、用途和操作区

当前工具清单应以真实能力为准，现阶段至少包括：

- 视频压缩

后续新增工具应在这个模块中按统一规则接入，而不是散落到 `Dashboard` 或其他知识页中。

### Nodes

`Nodes` 是未来 Knowledge 主线的结构化对象列表页。

当前职责：

- 作为知识对象的管理入口预留位置
- 未来承接工具之外的对象，如场景、经验、资源、项目、流程节点等

当前阶段要求：

- 保留模块壳和语义
- 不强行灌入示例节点

### Graph

`Graph` 是对象关系视图的预留模块。

当前职责：

- 预留关系化表达入口
- 为未来展示工具、问题、方案、经验之间的关系提供容器

当前阶段要求：

- 保留入口和页面结构
- 不为了视觉效果生成无业务意义的关系图

### Roadmaps

`Roadmaps` 是未来路线管理和阶段规划模块。

当前职责：

- 预留从“对象集合”走向“行动路径”的承载位
- 后续用于组织工具建设顺序、知识沉淀顺序或某个场景的解决路线

当前阶段要求：

- 保持模块存在
- 不预设大而全的路线模板

## 当前推荐的用户认知路径

Hagsyn 当前阶段的用户认知路径应为：

1. 进入 `Dashboard`，理解当前已有的真实能力
2. 进入 `Tools`，直接使用视频压缩等真实工具
3. 在未来有真实整理需求时，再逐步使用 `Nodes / Graph / Roadmaps`

也就是说，当前的信息架构重心应明显落在 `Tools`，而 Knowledge 相关模块更多承担“稳定存在、等待真实驱动”的角色。

## 模块间关系

### Dashboard 与 Tools

`Dashboard` 负责汇总与引导，`Tools` 负责实际执行。二者关系是“总览 -> 操作”。

### Tools 与 Nodes

后续当某个工具产生稳定经验、规则、输入模板或适用场景时，可以逐步沉淀为 `Nodes` 中的知识对象。

### Nodes 与 Graph

`Nodes` 负责对象本体，`Graph` 负责对象关系表达。

### Nodes 与 Roadmaps

`Nodes` 中的真实对象在未来可以成为 `Roadmaps` 的组成步骤或依赖项。

## 当前不建议的架构走向

为避免产品语义混乱，当前阶段不建议出现以下情况：

- 把 `Dashboard` 做成所有功能的混合页
- 把 `Tools` 和 `Nodes` 做成相同含义的双份目录
- 在 `Graph` 中放与真实对象无关的装饰性演示图
- 在 `Roadmaps` 中提前塞入未经验证的宏大路线

## 当前阶段的信息架构结论

Hagsyn 的信息架构应保持“工作台骨架稳定、Tools 明确优先、Knowledge 有序留白”的状态。

只要这个架构稳定，后续无论是继续扩充工具，还是逐步开启知识化能力，都可以在统一语义下持续演进。
