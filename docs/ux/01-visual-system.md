# Visual System

## 主题体系

当前统一使用三套主题：

- Midnight
- Graphite
- Pearl

三套主题的目标不是追求不同人格，而是在同一产品气质下提供不同阅读感受。

## 配色原则

- 深色主题优先服务工作台场景
- 亮色主题作为阅读和轻办公补充
- 主强调色用于操作、可点击状态和关键视觉锚点
- 状态色用于表达可用、进行中、规划中、错误等语义

## 核心色彩角色

- 背景色：定义整体基调
- 面板色：定义信息容器
- 边框色：定义层级和边界
- 主色：操作和焦点
- 辅助色：强调次级结构
- 语义色：成功、警告、错误、等待

## 字体原则

- 中文与界面正文使用 `IBM Plex Sans`
- 品牌、技术标签和少量结构化信息使用 `JetBrains Mono`
- 不使用夸张展示字体
- 不依赖字号堆砌层级

## 圆角与边框

- 页面级面板保持小到中等圆角
- 工具卡片、状态块、结果卡片保持统一圆角体系
- 用清晰边框区分层级，不用大片阴影制造假层次

## 阴影与景深

- 阴影只用于轻度抬升面板
- 不做漂浮卡片堆叠感
- 不做过强的 Glass 或 3D 效果

## 统一性要求

- 同一页面内的卡片、表单、按钮、标签使用统一视觉规则
- 新增工具页必须沿用现有视觉系统，不允许每个工具自成一套样式
