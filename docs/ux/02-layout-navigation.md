# Layout And Navigation

## 全局布局

Hagsyn 默认使用三栏结构：

1. 左侧导航栏
2. 中间主工作区
3. 右侧详情说明栏

## 三栏职责

### 左侧导航栏

负责：

- 模块切换
- 当前所在位置提示
- 品牌识别

不负责：

- 复杂操作
- 表单提交
- 过多状态堆叠

### 中间主工作区

负责：

- 当前模块的核心任务
- 工具目录
- 工具工作区
- Dashboard 信息块

这是用户真正完成任务的区域。

### 右侧详情栏

负责：

- 当前模块说明
- 工具边界
- 使用提示
- 状态补充信息

它是辅助解释层，不应替代主工作区。

## 导航原则

- 一级导航固定为产品主模块
- 当前模块必须高亮
- 子级状态尽量通过 hash 或内部状态表达，不增加新的左侧层级

## 路由原则

当前推荐：

- `#dashboard`
- `#tools`
- `#tools/video-compress`
- `#nodes`
- `#graph`
- `#roadmaps`

这保证：

- 产品壳稳定
- 工具进入路径清晰
- 刷新后仍可回到当前工作区
