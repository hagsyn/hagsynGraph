# Empty State Guidelines

## 原则

Hagsyn 不再使用 demo 数据填补空白模块，因此空状态必须被认真设计。

## 空状态表达目标

- 诚实
- 不挫败
- 不伪装成已完成
- 给出后续建设方向

## 允许表达

- 当前保留模块结构
- 等待真实需求接入
- 后续将由真实场景驱动建设

## 禁止表达

- 假造演示节点
- 假造路线图
- 用占位统计营造“系统很完整”的错觉

## 模块级空状态建议

### Nodes

说明该模块未来承载真实知识对象，而不是默认节点库。

### Graph

说明图谱位置已保留，但等待真实关系结构接入。

### Roadmaps

说明路线图模块等待真实建设路线，而不是演示路线。

## 工具模块中的空状态

如果没有激活某个工具，应明确提示用户从工具目录中选择一个真实工具进入工作区。
