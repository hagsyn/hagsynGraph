# Component Standards

## 工具卡片

工具卡片必须包含：

- 工具名称
- 一句话说明
- 当前状态
- 标签
- 主操作按钮
- 辅助说明按钮

工具卡片的目标是帮助用户判断“这是不是我现在要用的工具”，而不是展示大量元信息。

## 状态标签

推荐状态：

- 已可用
- 规划中
- 待建设
- 实验中

状态标签应简短、统一、可扫描。

## 结果卡片

用于展示工具执行后的结果。

当前视频压缩结果卡片应统一包含：

- 输入对象名
- 输出对象名或输出路径
- 核心数值变化
- 主下载动作

## 详情栏说明块

右侧详情栏建议采用：

- 标题
- 简要说明
- 标签
- 模式说明
- 边界说明

## 按钮规范

- 主按钮用于关键操作
- 次按钮用于辅助操作
- 不使用过多视觉等级
- 不用“伪胶囊装饰按钮”替代清晰操作语义

## 表单规范

- 表单必须有明确 label 或明显上下文
- 输入控件尺寸统一
- 模式选择应优先使用单选项而不是下拉

## 空状态组件

空状态不是失败，也不是错误，它是“当前尚未有真实内容”。

因此必须：

- 说明为什么为空
- 说明未来会承载什么
- 不制造假的已完成感
