# Tool Workspace Pattern

## 目标

所有进入 `Tools` 模块的真实工具，后续都应遵循同一工作区模式。

## 标准模式

### 第一层：工具目录

Tools 首页负责展示工具卡片列表。

每个工具卡片至少有两个动作：

- 使用
- 查看说明

### 第二层：工具工作区

点击“使用”后，不跳出产品壳，而是在当前 `Tools` 模块内切换到具体工具工作区。

### 第三层：详情说明栏

右侧详情栏展示该工具的：

- 工具说明
- 模式说明
- 当前边界
- 使用提醒

## 工作区原则

- 主工作区必须支持任务完成
- 结果展示与输入流程在同一工作区内闭环
- 工具之间复用同一布局模式

## 当前样板：视频压缩

视频压缩工作区结构：

1. 上传区
2. 模式区
3. 结果卡片区
4. 下载动作

后续新工具应尽量用相同的总体结构，而不是每个工具重新发明页面组织方式。
