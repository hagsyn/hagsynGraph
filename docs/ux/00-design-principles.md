# Design Principles

## 目标

Hagsyn 的界面不是营销页，也不是为了展示炫技效果而存在。它的核心目标是承载真实工具、真实工作流程和后续真实知识沉淀。

## 总原则

1. 工作台优先于展示感
2. 真实工具优先于 demo 数据
3. 信息层级清晰优先于装饰感
4. 工具工作区必须可直接进入并完成任务
5. 空状态要诚实表达“尚未建设”，而不是用假数据填满

## 产品类型判断

Hagsyn 当前属于：

- Developer Tool
- Personal Workbench
- Tool Hub

因此其设计应保持：

- 克制
- 高信息密度但不拥挤
- 明确导航
- 明确状态
- 可持续扩展

## 视觉表达原则

- 不做 landing page 化表达
- 不做强营销式 hero
- 不用大面积无意义渐变或装饰块
- 不依赖插画解释功能
- 优先用结构、间距、边框和层级表达专业感

## 功能表达原则

- 每个真实工具都应具备清晰入口
- 进入工具后，工作区必须直接服务于任务完成
- 详情栏用于解释边界、状态和说明，不抢主操作区
- 页面上的每个区块都应服务于“做事”，而不是填充版面
