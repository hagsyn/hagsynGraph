# Graph Shell SOP

## 适用场景

当任务涉及 `Graph` 模块的关系工作区、关系表达语义、图谱占位方式或空关系状态时使用。

## 前置检查

1. 确认当前是否已有真实对象和真实关系来源
2. 确认任务是在表达关系，而不是对象本体或路线组织
3. 检查页面是否有滑回“演示图谱”或“假画布”的风险

## 执行步骤

1. 保持 `Graph` 的角色为“对象关系工作区”
2. 没有真实关系时，不展示假画布或假连接线
3. 主区优先承载：
   - 关系工作区头部
   - 关系主空状态卡
   - 关系语义清单
   - 真实接入前提说明
   - 当前建设边界
4. 右侧详情栏说明：
   - 模块说明
   - 关系类型
   - 当前边界
   - 接入条件
5. 所有文案都应强调“未来承接真实关系”，而不是“图谱已准备就绪”

## 自校验步骤

1. `Graph` 是否仍然是关系工作区，而不是概念展示页
2. 是否没有假节点、假边或假关系统计
3. 是否清楚说明真实关系将来自哪里
4. 是否没有让 `Graph` 过早承担主产品价值
5. 关系类型是否足够清晰但不过度泛化

## 常见失败点

- 画出没有真实数据支撑的关系图
- 用“智能图谱”“自动发现关系”这类文案制造完成感
- 把 Graph 变成主要卖点而不是 Knowledge 壳层
- 右侧栏没有关系语义和接入边界说明
