# Roadmaps Shell SOP

## 适用场景

当任务涉及 `Roadmaps` 模块的路线工作区、阶段路径展示、建设路线组织或空路线状态时使用。

## 前置检查

1. 确认当前是否已有被真实定义的建设路线或阶段任务
2. 确认任务是在组织路径，而不是对象本体或关系表达
3. 检查页面是否会滑向“宏大 demo 路线”或空泛阶段模板

## 执行步骤

1. 保持 `Roadmaps` 的角色为“真实路线工作区”
2. 没有真实路线时，不自动生成宏大阶段表
3. 主区优先承载：
   - 路线类型说明
   - 当前路线输入条件
   - 路线工作区预览
   - 当前建设边界
4. 右侧详情栏说明：
   - 路线模块职责
   - 路线类型标签
   - 当前边界
   - 接入条件
5. 让路线只在真实建设需要时进入，而不是为页面完整度而存在

## 自校验步骤

1. `Roadmaps` 是否仍然是路线壳，而不是假规划页
2. 是否没有预设宏大 demo 路线
3. 是否清楚写出“什么情况下路线才会真实进入”
4. 是否把产品建设路线、工具接入路线、知识沉淀路线区分开
5. 是否没有用路线模板伪造“项目已经很完整”

## 常见失败点

- 预先摆出很多空泛阶段
- 把路线图写成只读宣传内容
- 没有真实任务支撑就强推路线管理
- 混淆路线、对象和关系三者的职责
